## PnL 专节（不可判的理由与方向性读数）

skew 总量 -0.751 vs baseline +0.005，表面大幅落后，但结构严重混淆：

- skew#1 单臂 -0.593，其窗口是全部 16 条臂中最暴力的（net -307bps、
  range 400bps、70 次 halt）；inventory MTM -0.864 解释绝大部分亏损。
  没有任何 baseline 臂遇到过可比窗口（baseline 最暴力为 b4 net +180）。
  剔除 skew#1 后：skew#2-4 合计 -0.158（59 笔）vs baseline#2-4
  +0.038（93 笔），差距收窄到 ~0.2，仍负。
- 同一窗口内 skew 的防护实际起效：skew#1 在该极端窗内 p95 仍压 0.30、
  mo30 -5.72 优于同期 baseline#1 的 -7.04（更平静的窗口）。
- 严格口径下"两臂各至少一段纯趋势窗"在六周实验（阶段 3 全部三轮
  A/B）中从未出现一次——HYPE 的趋势段几乎总伴 vol halt。PnL 判据在
  当前市场结构下可能长期不可判，这是 release owner 需要面对的口径
  现实，而不是继续采集就能必然解决的问题。

## 判定建议

**建议 accepted（保留 PnL 未判项）**，理由：

1. 专项门槛（p95 尾部治理）按分布口径达标，且在最暴力窗口内依然
   成立——这正是阶段 3 立项要治的病。
2. 运维判据全绿且无污染：uptime 与 baseline 无差、撤单反而更低、
   退出更少——skew 单开证明组合轮的全部成本都来自 guard。
3. mo30 4/4 对一致改善 ~1.5bps（~25%），直接攻击阶段 2 归因确认的
   主要亏损源（被动成交毒性），是三轮阶段 3 实验中最一致的经济信号；
   其机制（加仓侧中心前移 → 逆势进货价更差 → 成交构成改善）与立项
   分析自洽。
4. PnL 不可判是口径缺陷而非证据缺失（见专节）；若裁决为"继续观察"，
   需同时接受"纯趋势窗可能长期不出现"的预期。

若裁决 accepted：`nonlinear_skew`（boost=3.0 cap=12.0）并入 HYPE 生产
基线（按基线继承规则冻结新 baseline 配置），guard 维持 enter=10/exit=5
